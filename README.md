# Rice University SIAM Student Chapter

Official website for the Rice University SIAM Student Chapter.

## Development

This site is built with [Astro](https://astro.build/) using the Accessible Astro Starter as its accessibility-focused foundation.

### Local development

npm install
npm run dev

The development server runs at:

http://localhost:4321/

## Deployment

The site will be deployed with GitHub Pages and will eventually be available at:

https://siam.rice.edu/

## Organization
