# Rice print files

Rice EPS, PDF, and AI files are **not** in this repository. Each vector file is about 2 MB, and the university pack also includes mesh and white-border specialty art that the website does not use.

Keep the original **University Logos** Box download (or `University Logos.zip`) on an officer machine. Web SVG/PNG already live in `public/images/branding/rice/`.

## Grab these for posters and flyers

From `Rice Logo/Rice logo eps files/`:

- `Rice_Logo_280_Blue.eps` — light backgrounds
- `Rice_Logo_Reverse_White.eps` — dark backgrounds
- `Rice_Logo_Black.eps`

From `Rice Owl/Rice Owl eps files/` if you need the owl as decoration (not as a logo):

- `Rice_Owl_Flat_280_Blue.eps`
- `Rice_Owl_Flat_White.eps`

From `__Preferred Logo Stacked with _University___` when you want the full university name:

- stacked horizontal/vertical `print/COLOR` and `print/WHITE ALL` EPS

Shield-only web files are in `public/images/branding/rice/shield-rice-*` for the approved favicon. Do not copy the academic seal. Shield EPS stays in the Box download (large).

If Public Affairs later issues a SIAM Student Chapter lockup, put the print files in this folder as `logo-rice-siam-student-chapter-{color}.eps`.
