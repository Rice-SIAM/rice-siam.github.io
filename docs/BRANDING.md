# Branding

Rice and SIAM marks this site displays. Do not redraw, recolor, crop, or combine them into a homemade lockup.

Other Rice and SIAM web files, and the SIAM print EPS files, are in the officers’ internal repository under `branding/rice/` and `branding/siam/`. Rice print EPS stays in the University Logos Box download. Color values are in `src/data/brand-colors.yaml`.

The files are in `public/images/branding/`.

## Files

| File                                   | Use                                                                           |
| -------------------------------------- | ----------------------------------------------------------------------------- |
| `rice/logo-rice-blue.svg`              | Shield + **RICE** on light backgrounds (header, flyers)                       |
| `rice/logo-rice-white.svg`             | Shield + **RICE** on dark backgrounds (header, footer)                        |
| `rice/owl-flat-blue.svg`               | Faint owl on event and newsletter flyers. Decoration only                     |
| `rice/owl-flat-white.svg`              | Faint owl in the homepage hero. Decoration only                               |
| `siam/logo-siam-blue.png`              | SIAM wordmark on light backgrounds. Link it to `https://www.siam.org`         |
| `siam/logo-siam-white.png`             | SIAM wordmark on dark backgrounds (footer). Link it to `https://www.siam.org` |
| `siam/siam-official-color-palette.png` | SIAM’s published palette, referenced by `src/data/brand-colors.yaml`          |

The white SIAM mark is a transparent PNG, so it disappears on a white page.

## Rules

- The header is the Rice mark plus the typeset chapter name. The shield alone is the favicon, `public/favicon.svg`, with the PNG sizes beside it. Public Affairs approved that use. Do not use the academic seal.
- Link every SIAM wordmark to `https://www.siam.org`. Do not use an “in cooperation with SIAM” mark as the chapter logo.
- These SVGs use `#002169`. Site CSS uses Rice Blue `#00205B` from [brand.rice.edu/colors](https://brand.rice.edu/colors).
- A custom chapter mark needs [SIAM Marketing](https://www.siam.org/advertising/contact-siam-marketing-staff/) review. A Rice lockup request uses [publicaffairs.rice.edu/logo-proj-req-form](https://publicaffairs.rice.edu/logo-proj-req-form) and the words “SIAM Student Chapter”.
- To show another mark, copy that file from the internal repository and reference it from a page. Leave files the site does not display out of `public/images/branding/`.
