The Rice University SIAM Student Chapter wants this website to be accessible to everyone, regardless of ability or circumstance. We are working to improve the experience for all visitors and to follow relevant accessibility standards.

## Measures to support accessibility

Rice SIAM takes the following measures to support accessibility of this website:

- Include accessibility throughout the development process
- Review accessibility during code review
- Welcome accessibility feedback

## Conformance status

The [Web Content Accessibility Guidelines (WCAG)](https://www.w3.org/WAI/standards-guidelines/wcag/) define requirements for making web content more accessible. WCAG defines three levels of conformance: Level A, Level AA, and Level AAA.

This website aims to conform to WCAG 2.2 Level AA. It is currently **partially conformant**. Partially conformant means that some parts of the content may not yet fully meet the standard. We will update this statement after a full accessibility review.

## Feedback

Please tell us if you encounter an accessibility barrier on this website through the
<Link href="/contact">contact page</Link>. We will add a public email address there when one is available. We will try
to respond to accessibility feedback within 10 business days.

## Technical specifications

Accessibility of this website relies on the following technologies:

- HTML
- WAI-ARIA
- CSS
- JavaScript, used only where needed for navigation and preference controls

These technologies are used with modern browsers and assistive technologies.

### Accessibility features

This website includes the following accessibility features:

- Skip link to bypass navigation and jump to main content
- One primary heading (`h1`) per page and a logical heading hierarchy
- Landmark regions (`header`, `nav`, `main`, `footer`)
- Keyboard access to interactive elements
- Visible focus indicators
- Color contrast intended to meet WCAG AA
- Dark and light themes, plus support for operating-system contrast preferences
- Reduced-motion support for visitors who prefer less animation
- Responsive layout
- Semantic HTML
- Alternative text support for informative images

## Limitations and alternatives

Despite our efforts, some content may still present barriers. Please
<Link href="/contact">contact us</Link> if you encounter an issue.

## Assessment approach

Rice SIAM assesses accessibility through:

- Self-evaluation by maintainers
- Automated testing with axe
- Keyboard-only navigation testing
- Additional review before the production domain is mapped by Rice University IT
